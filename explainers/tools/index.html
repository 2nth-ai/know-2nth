tools · Catalog for the 2nth.ai agents

The tools Grant, Penny, Leo, Grace, and Katharine actually use.

The 2nth.ai fractional agents do real work. To do real work, agents need real tools, with real permissions, and they have to leave a real trail — the proof of work a human auditor (or a partner) can replay. The same tools have to be callable by humans through a form, not just by agents through MCP, so the audit log captures both. This catalog is the opinionated, off-the-shelf shortlist we use, and the wiring that makes it credible. It is meant to be copied: pick the tools, copy the policies, point your agents at them.

01 · The substrate

Eight things every agent shares.

Before a single vendor MCP server lights up, an agent needs a runtime, a protocol, a permission gate, an audit trail, a sandbox for code, an identity, a dual-use bridge, and a trace contract. These are the eight load-bearing picks. Each is verified production in 2026 and self-hostable, so a partner can clone the whole pattern.

04 · Proof of work

Every call leaves a trail. Four artifacts. One join key.

Every tool call — agent or human — emits the same four artifacts, all tied by a single run_id. A partner reviewing the showcase can pivot from any one of them to the others, replay the full agent run in the Langfuse UI, and verify nothing happened off-record.

OTel GenAI span → Langfuse

The replayable trace. Agent prompts, tool args, decisions, latencies, costs — everything an auditor needs to reconstruct what happened, including the agent's reasoning.

D1 row in tool_calls

The durable summary. Cheap to query, indexed by agent, tool, decision, time. Powers dashboards and approval queues without paging the trace store.

R2 artifact

When the tool produced a file (image, PDF, CSV, audio), it lands at runs/{run_id}/{filename}. The trace and the row both link to it.

Approval record

Destructive actions block until a human decides. The decision is its own row in approvals with approver id, time, and note. A "yes" is as audited as a "no".

05 · Dual-use pattern

One function. Human form or agent tool.

A tool that mutates state lives once, as an Inngest function. The function is callable from a plain HTML form (humans) or from the MCP gateway (agents). The Langfuse trace is identical except for one attribute: source. That's how the audit log treats humans and agents the same way — because the code path is the same.

Worked example · penny.send-email

  1. Agent path: Penny calls penny.send_marketing_email via MCP. The gateway logs decision=approval_required and fires Inngest event penny.send_email.requested with source: "agent".
  2. The Inngest function pauses on approval.decided. A human approver sees a card in the audit UI, reviews the proposed copy + audience, clicks approve.
  3. The function unpauses, calls the HubSpot Marketing Email API, writes the result back to the gateway, closes the tool_calls row.
  4. Human path: a marketing manager opens know.2nth.ai/tools/penny/send-email.html, submits the same form. The form POSTs to a Worker which fires penny.send_email.requested with source: "human". No pause — the form submission is the approval.
  5. The Langfuse trace shape is identical in both paths. Only the source attribute differs.
06 · What this is not

The honest disclaimers.

Not a hosted product

2nth.ai does not run this as a multitenant service. Partners deploy their own copy of the agent-platform repo on their own Cloudflare + Fly accounts.

Not a model gateway

This catalog gates tool calls. Model traffic (Anthropic, Vertex, Bedrock) goes direct from the agent. Use Cloudflare AI Gateway for model-side routing.

Not finished

As of 2026-05-17 the scaffold exists; vendor MCP wiring + the per-tool leaves on this site are in active build. The catalog is intentionally published early so partners can react to the shape.

Not the only way

We picked Cerbos over Permit.io, Langfuse over LangSmith, Inngest over Trigger.dev for specific reasons (OSS + self-hostable + partner-copyable). Other stacks land at the same architecture; ours is the one we're prepared to defend in a pilot review.
